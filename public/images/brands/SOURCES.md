# Sources des identités visuelles

Ces fichiers servent uniquement à illustrer les articles qui citent directement les organisations ou produits concernés. Les marques restent la propriété de leurs titulaires et leur présence ne signifie aucun partenariat avec DIONYSIA.

- Apple, DeepSeek, Anthropic, Google, Mistral AI, NVIDIA, Meta, Alibaba Cloud, Qwen, GitHub, Hugging Face, Stripe, PayPal, TypeScript, Bun, Debian et Kimi : fichiers SVG distribués par [Simple Icons](https://simpleicons.org/), à partir des identités visuelles indiquées par chaque marque.
- OpenAI : symbole vectoriel issu du paquet Simple Icons ; utilisation éditoriale conforme aux [règles de marque OpenAI](https://openai.com/brand/).
- Amazon Web Services : symbole vectoriel issu du paquet Simple Icons.
- Microsoft : wordmark chargé depuis le domaine média officiel de Microsoft ; voir les [règles de marque Microsoft](https://www.microsoft.com/trademarks).
- Nous Research : avatar de l’organisation depuis son [organisation GitHub officielle](https://github.com/NousResearch).

Les drapeaux de l’Union européenne, de la France, de la Chine, des États-Unis, du Royaume-Uni et de l’Allemagne sont des fichiers SVG provenant de [FlagCDN](https://flagcdn.com/).
